⚙ Definições de publicação (não é login do painel)
O painel é de acesso direto, sem autenticação. Para gravar no repositório é necessário um token GitHub com acesso de escrita ao repositório. O token fica apenas nesta sessão do navegador e não é enviado ao site público. Não partilhes este painel com pessoas não autorizadas enquanto o token estiver ativo.
Não coloques o token no código. Ao fechar a sessão do navegador, o token temporário será eliminado.
